  edge requests across all members, so slice FFs sharing the clock also settle
  at falls: one extra idempotent settle per cycle, only for DISABLED designs.

Implementation/refusal details:
  MultiplierPipeline.both_edges and Alu54.both_edges select the HD09 uniform
  disabled-divider profile. Event captures use both clock polarities for non-C
  stages; C uses every rising edge. Enabled C keeps its old divider. GSR active
  at a rise holds non-C stages through the following fall. The planner refuses
  mixed active divider modes and ALU/MULT disagreement; standalone INPUTC remains
  outside the measured executable profile.
  Fast DSP refuses CLK_DIV=DISABLED from fast_dsp.rs. fast.rs currently constructs
  DSP groups with group(c.clock, true, false), schedules Edge::Rising and emits
  rise{g} guards. It needs per-capture edge selection, both requested group
  polarities, and rising/falling capture guards. C must remain rising-only and
  omit its divider in DISABLED. Free HD09m/p UART and random fast/kernel DISABLED
  comparisons cannot run until that work is done; tests assert the clear refusal.
  FlipFlop.preload: Option<Input> is the HS02 source. None retains LSR/REGSET;
  Some(M) means PRLD even when M is constant. register.config.reset supplies the
  LSR input and sync/async kind. The fast.rs register-update loop contains only
  the agreed ensure against Some(preload), with the register's driver label.
  Event PRLD uses M over CE, follows it at level for ASYNC, and returns X on a
  same-instant M change and LSR release (tracked across capture waves). Configured
  initialization samples settled M, otherwise X; the board startup rule is one
  observation. REGSET does not seed PRLD startup or choose its preload value.
  CEMUX behavior is unchanged.
